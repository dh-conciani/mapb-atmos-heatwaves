# Fact-sheet de acurácia

`src/generate_factsheet.py` gera um PDF em formato 16:9, com linguagem visual inspirada no fact-sheet MapBiomas Atmosfera: faixa cromática superior, grandes números, blocos de decisão e paleta verde/ciano/laranja/roxo.

O PDF é deliberadamente conciso e orientado à decisão técnica. O sumário executivo vem primeiro e a metodologia, resultados e limitações são apresentados depois.

Produto gerado por `./run_all.sh`:

```text
outputs/generated/report/MapBiomas_Atmosfera_Heatwaves_Accuracy_Factsheet.pdf
```
